TERRA V PANORAMA TEXTURES

Drop your equirectangular (2:1) textures into this folder using these exact filenames:

albedo.jpg       Earth base-color/albedo map (required)
normal.jpg       Normal map (optional)
roughness.jpg    Roughness map (optional)
metalness.jpg    Metalness map (optional)
ao.jpg           Ambient-occlusion map (optional)
skybox.jpg       Milky Way / space equirectangular skybox (required)

The website loads these files automatically. No upload controls are used.
Replace the existing albedo.jpg and skybox.jpg files with your own maps.
For PNG/WebP files, update the filename in panorama.js accordingly.
